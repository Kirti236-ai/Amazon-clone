# Amazon-clone
A responsive, pixel-perfect frontend clone of the Amazon.com homepage built entirely from scratch using HTML5 and CSS3. This project focuses on replicating the core structural layout, visual design, and user interface elements of the live Amazon website.

## ⚡ Key Features Replicated

To capture the true feel of Amazon, I paid close attention to replicating these key visual components:

* **Hero Image Carousel:** Positioned the massive background hero banner with the transparent gradient overlay that fades into the page content body.
* **Product Card Grid Layouts:** Leveraged **CSS Flexbox / Grid** to style multi-column product widgets, tracking uniform padding, box-shadows, and "Shop Now" text links.
* **Back to Top & Footer:** Replicated the multi-tiered footer including the signature green-blue "Back to top" button and structured link categories.

---

## 🛠️ Core Technologies Used

* **HTML5:** For semantic document structure (`<header>`, `<nav>`, `<main>`, `<footer>`).
* **CSS3:** For advanced styling, positioning (`position: absolute/relative`), and custom layouts.
* **CSS Flexbox & Grid:** Used extensively to control the complex alignment of the product matrices.
* **Google Fonts / FontAwesome:** Used to match font styles and UI icons as closely as possible.
